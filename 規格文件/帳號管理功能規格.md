# 帳號管理功能規格

## 一、基本資訊

| 項目 | 說明 |
|---|---|
| 功能名稱 | 帳號管理 |
| 所屬模組 | 系統營運管理／帳號權限管理 |
| 畫面連結 | [開啟帳號管理畫面](../backend/account-management.html) |
| 主要功能 | 查詢、檢視、編輯帳號資料 |
| 目前狀態 | 前端展示版，資料儲存於頁面記憶體；重新整理後恢復範例資料 |

## 二、頁面入口

後臺選單路徑：

> 系統營運管理 → 帳號權限管理 → 帳號管理

## 三、查詢功能

### 3.1 查詢條件

| 欄位 | 類型 | 選項／規則 |
|---|---|---|
| 關鍵字 | 文字輸入 | 比對姓名、身分證／居留證號、手機、電子信箱；採包含比對 |
| 角色 | 下拉選單 | 全部角色、民眾、機關 |
| 機關名稱 | 下拉選單 | 全部機關、國家住宅及都市更新中心、內政部國土管理署、新北市政府、臺北市政府、桃園市政府、臺中市政府、臺南市政府、高雄市政府 |
| 機關角色 | 下拉選單 | 全部機關角色、一般機關人員、查調授權人員 |
| 帳號狀態 | 下拉選單 | 全部狀態、啟用、停用 |

### 3.2 查詢操作

| 操作 | 行為 |
|---|---|
| 查詢 | 依所有已填條件篩選資料，並回到第 1 頁 |
| 重設 | 清除所有條件，顯示全部帳號，並回到第 1 頁 |
| 展開／收合 | 顯示或隱藏查詢條件區塊 |

## 四、帳號清單

### 4.1 欄位

| 欄位 | 顯示內容 |
|---|---|
| 真實姓名 | 使用者姓名 |
| 身分證／居留證號 | 身分識別號碼 |
| 聯絡手機 | 手機號碼 |
| 電子信箱 | Email |
| 信箱驗證 | 已驗證／未驗證 |
| 角色 | 民眾／機關 |
| 機關名稱 | 所屬機關；民眾顯示「--」 |
| 機關角色 | 一般機關人員／查調授權人員；民眾顯示「--」 |
| 帳號狀態 | 啟用／停用 |
| 操作 | 檢視、編輯 |

### 4.2 顯示與分頁

- 每頁顯示 20 筆。
- 顯示總筆數及目前資料範圍。
- 提供上一頁、頁碼、下一頁。
- 第 1 頁停用上一頁；最後一頁停用下一頁。
- 無符合資料時顯示「查無符合條件的帳號。」。
- 具備響應式表格，支援小尺寸螢幕瀏覽。

## 五、檢視帳號

點擊「檢視」後開啟「檢視帳號資料」視窗。

| 項目 | 規則 |
|---|---|
| 顯示資料 | 帳號基本資料、信箱驗證資訊、首次身分驗證資訊、權限說明 |
| 編輯狀態 | 所有欄位唯讀 |
| 儲存按鈕 | 隱藏 |
| 可執行操作 | 關閉視窗 |

## 六、編輯帳號

點擊「編輯」後開啟「編輯帳號資料」視窗。

### 6.1 編輯欄位

| 欄位 | 類型 | 必填 | 可編輯 | 限制 |
|---|---|---:|---:|---|
| 真實姓名 | 文字輸入 | 是 | 是 | 最長 100 字元 |
| 身分證字號／居留證號 | 文字輸入 | 是 | 否 | 最長 20 字元 |
| 聯絡手機 | 電話輸入 | 是 | 是 | 最長 20 字元 |
| 電子信箱 | Email 輸入 | 是 | 是 | 最長 254 字元，須符合 Email 格式 |
| 角色 | 下拉選單 | 是 | 是 | 民眾、機關 |
| 機關名稱 | 下拉選單 | 機關時必填 | 角色為機關時可編輯 | 民眾時隱藏、停用 |
| 機關角色 | 下拉選單 | 機關時必填 | 角色為機關時可編輯 | 民眾時隱藏、停用 |
| 帳號狀態 | 下拉選單 | 是 | 是 | 啟用、停用 |

### 6.2 角色規則

| 角色／機關角色 | 權限說明 |
|---|---|
| 民眾 | 不具後臺機關或查調資料檢視權限；機關欄位隱藏 |
| 一般機關人員 | 可使用一般機關功能，不具查調資料檢視權限 |
| 查調授權人員 | 具一般機關功能及所屬機關案件的查調資料檢視權限 |

### 6.3 儲存行為

- 儲存前執行必填及格式驗證。
- 身分證／居留證號不可修改。
- 民眾帳號儲存時清除機關名稱及機關角色。
- 儲存成功後重新套用目前查詢條件並更新清單。
- 顯示成功訊息：`已更新「{姓名}」的示範資料。`
- 關閉編輯視窗。

## 七、信箱驗證資訊

| 資訊 | 顯示內容 |
|---|---|
| 電子信箱驗證狀態 | 已驗證／未驗證 |
| 電子信箱驗證時間 | 驗證時間；未驗證顯示「尚未驗證」 |
| 首次身分驗證方式 | 自然人憑證、行動自然人憑證、健保卡號與身分證字號比對 |
| 首次身分驗證時間 | 首次驗證時間 |

若修改電子信箱，儲存後將信箱驗證狀態改為「未驗證」，並清除驗證時間。

## 八、空狀態與提示

| 情境 | 顯示／處理 |
|---|---|
| 查無帳號 | 顯示「查無符合條件的帳號。」 |
| JavaScript 未啟用 | 顯示「請啟用 JavaScript 以查看帳號資料。」 |
| 欄位驗證失敗 | 不執行儲存，提示使用者修正欄位 |
| 示範資料儲存 | 僅套用目前頁面，重新整理後恢復原始範例資料 |

## 九、目前未提供功能

- 新增帳號
- 刪除帳號
- 重設密碼
- 重新寄送信箱驗證信
- 強制完成信箱驗證
- 編輯身分證／居留證號
- 後端 API 儲存及正式權限控管

## 十、驗收重點

- 可由後臺選單或[畫面連結](/backend/account-management.html)進入帳號管理。
- 可依關鍵字、角色、機關、機關角色及帳號狀態查詢。
- 查詢與重設後回到第 1 頁。
- 清單正確顯示帳號欄位、狀態及操作按鈕。
- 檢視模式不可編輯且不顯示儲存按鈕。
- 編輯模式不可修改身分證／居留證號。
- 民眾與機關角色切換時，機關欄位顯示及權限說明正確。
- 修改電子信箱後，信箱驗證狀態重設為未驗證。
- 儲存成功後清單更新並顯示成功訊息。
- 分頁、查無資料及未啟用 JavaScript 的提示正常顯示。
