# A6.3 訂閱管理

v1.10｜PostgreSQL｜時間：`timestamptz`，顯示時區：`Asia/Taipei`。招租通知流程見[招租通知規格](招租通知_規格.md)。

## 一、功能規則

登入會員只能操作自己的訂閱。`cancelled_at IS NULL` 為有效訂閱；通知程序依有效訂閱發送招租 Email，不另設通知開關。

| 功能 | 規則 |
|---|---|
| A 居住需求訂閱 | 每會員最多一筆，指向本人最新 SUBMITTED 問卷。問卷送出與訂閱 upsert 同一交易，鎖定會員防止舊版覆蓋；更新 survey_id、生效時間，保留訂閱日期。草稿不生效；不可取消 |
| B 搜尋條件訂閱 | 可多筆；保存當次區位、房型、預算、公設、生活機能、名稱關鍵字，不隨後續搜尋改變；相同條件可重複建立；不含 housing_status_codes |
| C 指定社宅訂閱 | 同會員同啟用社宅最多一筆有效訂閱；重複建立回傳已訂閱；取消再訂閱新增一列 |
| 取消 B／C | 只更新本人有效訂閱，保留首次取消時間及歷史，不影響其他訂閱。社宅停用不自動取消 |
| 列表 | A＋B 為已訂閱條件，C 為已訂閱社宅，各自計算有效筆數。A 固定第一列並標示居住需求問卷；其他依 subscribed_at DESC, id DESC。地區按縣市分組、未限制顯示「不限」、日期 YYYY/MM/DD |
| 更新／媒合推薦 | A 更新導向居住需求問卷；A／B 推薦帶完整條件至找社宅立即查詢；C 帶名稱並限制 housing_id |
| 取消確認 | B 顯示條件摘要，C 顯示社宅與地區；保留不異動，確認後移除該列並更新筆數 |

## 二、訂閱表 `member_subscription`

### 資料用途與類型

一列代表一位會員的一筆訂閱；三種類型共用此表，以 `subscription_type` 區分。此表不存寄信結果，通知紀錄另見[招租通知規格](招租通知_規格.md)。

| 類型 | 一列代表 | 條件來源 | 建立／更新方式 |
|---|---|---|---|
| A 居住需求訂閱 | 該會員唯一的居住需求訂閱 | `survey_id` 指向本人最新 SUBMITTED 問卷；不複製條件至本表 | 首次送出問卷時建立；後續送出更新同一列的 `survey_id`、`criteria_effective_at`、`updated_at`，保留 `id`、`subscribed_at`、`created_at`；不可取消 |
| B 搜尋條件訂閱 | 一次儲存的搜尋條件 | 本表的 B 專用欄位，保存當次條件，不隨後續搜尋改變 | 每次訂閱新增一列，相同條件可重複建立；取消時保留原列 |
| C 指定社宅訂閱 | 對一個指定社宅的訂閱 | `housing_id` | 同會員、同社宅僅一筆有效訂閱；重複建立回傳已訂閱，取消後重新訂閱新增一列 |

### 欄位定義

「必填＝是」設為 `NOT NULL`；「僅 A／B／C 必填」依類型用 `CHECK` 約束，不設全表 `NOT NULL`。預設值「無」表示不設資料庫預設值；必填欄位由服務寫入，選填欄位未填為 `NULL`。B 專用欄位在 A／C 一律為 `NULL`，不得寫入空陣列或其他值。

#### 識別與關聯

| 欄位 | 型態 | 必填 | 預設值 | 關聯 | 用途／規則 |
|---|---|---|---|---|---|
| id | uuid | 是 | `gen_random_uuid()` | PK | 訂閱識別碼 |
| member_id | uuid | 是 | 無 | FK → `member_profile.id` | 訂閱所屬會員；只能操作本人資料 |
| subscription_type | char(1) | 是 | 無 | — | `A`＝居住需求、`B`＝搜尋條件、`C`＝指定社宅 |
| survey_id | uuid | 僅 A 必填 | 無 | FK → `housing_demand_survey.id` | A 的條件來源；須為本人最新 SUBMITTED 問卷；B／C 必須為 `NULL` |
| housing_id | uuid | 僅 C 必填 | 無 | FK → `housing.id` | C 訂閱的社宅；建立時須啟用；A／B 必須為 `NULL` |

#### B 搜尋條件專用欄位

下列欄位僅 B 使用，不包含 `housing_status_codes`。空陣列代表該類條件未限制；`NULL` 端點代表租金該側未限制。

| 欄位 | 型態 | 必填 | 預設值 | 關聯 | 用途／規則 |
|---|---|---|---|---|---|
| housing_name | varchar(100) | 否 | 無 | — | 社宅名稱關鍵字；未填為 `NULL`，不是指定社宅名稱快照 |
| county_code | varchar(5) | 否 | 無 | FK → `county.county_code` | 縣市範圍；與 `living_area_id` 最多填一項，也可皆為 `NULL` |
| living_area_id | uuid | 否 | 無 | FK → `living_area.id` | 生活圈範圍；與 `county_code` 最多填一項，也可皆為 `NULL` |
| district_codes | text[] | 僅 B 必填 | 無 | 元素對應 `district.district_code`；由服務驗證 | 行政區代碼，可跨縣市；未選時由服務寫入空陣列 `'{}'` |
| room_type_codes | text[] | 僅 B 必填 | 無 | 元素對應 `housing_class` 的 `ROOM_TYPE` 代碼；由服務驗證 | 房型；未選時由服務寫入空陣列 `'{}'` |
| facility_codes | text[] | 僅 B 必填 | 無 | 元素對應 `housing_class` 的 `FACILITY_ITEM` 代碼；由服務驗證 | 公設；未選時由服務寫入空陣列 `'{}'` |
| life_function_codes | text[] | 僅 B 必填 | 無 | 元素對應 `housing_class` 的 `LIFE_FUNCTION` 代碼；由服務驗證 | 生活機能；未選時由服務寫入空陣列 `'{}'` |
| rent_min | integer | 否 | 無 | — | 月租下限，單位：元；`NULL` 為無下限 |
| rent_max | integer | 否 | 無 | — | 月租上限，單位：元；`NULL` 為無上限 |

#### 時間與取消紀錄

| 欄位 | 型態 | 必填 | 預設值 | 關聯 | 用途／規則 |
|---|---|---|---|---|---|
| subscribed_at | timestamptz | 是 | `now()` | — | 訂閱成立時間，供列表顯示及排序；A 更新問卷不改此值 |
| criteria_effective_at | timestamptz | 是 | 無 | A 取關聯問卷的 `submitted_at` | 條件生效時間，供通知排程判斷；A 每次送出問卷更新，B／C 建立時寫入與 `subscribed_at` 相同的時間 |
| created_at | timestamptz | 是 | `now()` | — | 資料列建立時間；建立後不變 |
| updated_at | timestamptz | 是 | `now()` | — | 資料列最後異動時間；更新問卷關聯或取消訂閱時由服務更新，不因 `DEFAULT` 自動更新 |
| cancelled_at | timestamptz | 否 | 無 | — | B／C 首次取消時間；未取消及 A 必須為 `NULL`，重複取消不覆寫 |
| cancel_reason | varchar(30) | 取消時必填 | 無 | — | B／C 取消時填 `MEMBER_REQUEST`；未取消及 A 必須為 `NULL` |

`subscribed_at` 是會員看到的訂閱日期，`criteria_effective_at` 是目前條件開始生效的時間，`created_at` 是資料列建立時間。A 更新問卷只更新條件生效時間及最後異動時間，不重設訂閱日期或另建訂閱列。`cancelled_at IS NULL` 即有效訂閱；社宅停用不自動填入取消時間。

### 資料驗證

| 驗證層 | 必要規則 |
|---|---|
| 資料庫 `CHECK`：類型與欄位 | `subscription_type` 限 A／B／C；A 必須有 `survey_id`，C 必須有 `housing_id`，其他類型對應欄位必須為 `NULL`；B 四個陣列必須非 `NULL`，所有 B 專用欄位在 A／C 必須為 `NULL` |
| 資料庫 `CHECK`：區位與預算 | `county_code`、`living_area_id` 不可同時有值；租金有值時必須非負，兩端皆有值時 `rent_min <= rent_max` |
| 資料庫 `CHECK`：取消 | `cancelled_at`、`cancel_reason` 必須同時為 `NULL` 或同時有值；有值時僅限 B／C、原因限 `MEMBER_REQUEST`，且 `cancelled_at >= subscribed_at`；A 兩欄永遠為 `NULL` |
| 服務：問卷與社宅 | A 驗證問卷歸屬、SUBMITTED 狀態及最新版本；問卷送出與訂閱 upsert 須同一交易並鎖定會員，避免舊版覆蓋。C 建立時驗證社宅啟用 |
| 服務：代碼與範圍 | 驗證代碼存在、所屬群組及行政區屬於指定縣市／生活圈範圍；陣列須去重且不得含 `NULL`。陣列元素不是資料庫 FK，不能省略服務驗證；失效代碼不可當成不限 |
| 服務：取消 | 只更新本人仍有效的 B／C 訂閱，同時寫入首次取消時間、原因及 `updated_at`；不刪除資料列，不影響其他訂閱 |

唯一性與查詢索引見第三章。

## 三、索引

| 表 | 索引 |
|---|---|
| member_subscription | UNIQUE `(member_id)` WHERE subscription_type = 'A' |
| member_subscription | UNIQUE `(member_id, housing_id)` WHERE subscription_type = 'C' AND cancelled_at IS NULL |
| member_subscription | INDEX `(member_id, subscribed_at DESC, id DESC)` WHERE cancelled_at IS NULL |
| member_subscription | INDEX `(subscription_type, criteria_effective_at)` WHERE cancelled_at IS NULL |
