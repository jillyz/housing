# 戶政查調資料表設計

日期：2026-11-24｜資料庫：PostgreSQL｜來源格式：變動長度、Unicode（UTF-8）JSON。

依據本次提供的 CQ03「個人基本資料」及 CQ26「全戶戶籍資料（完整姓名）」申請表，僅納入資料項目中標示「■」的欄位。代碼與內容取自 [戶政資料代碼彙整](戶政資料代碼彙整.md)。本文件為這兩張來源表單的欄位設計，與既有 CP03／P301 來源規格分開辨識。

## 長度與儲存原則

- 文字欄位使用 `varchar(n)`。`n` 是最大字元數，並非 UTF-8 位元組數；不因中文字使用多個位元組而將長度乘以 3。`varchar` 不會像 `char` 補滿空白。依據：[PostgreSQL 字元型別](https://www.postgresql.org/docs/current/datatype-character.html)。
- 來源以 `/` 區分固定及變動長度時，採變動長度上限。例如 `C3/C4` 採 4；姓名 `C6/C50;C200` 或 `C20/C50;C200`，考量中文姓名最多 50 字及原住民族文字姓名最多 200 字，統一採 `varchar(200)`。
- 日期來源為 `X7`，本設計以 `varchar(7)` 保留來源日期字串。用於計算年齡或設籍期間時，再依介接確認的日期編碼轉成 `date`；若為民國 `YYYMMDD`，年份須加 1911。空白或無法辨識的日期不得補造為有效日期。
- 以下代碼對照用於判讀。申請表未提供實際 JSON 範例，尚不能確認各欄回傳「代碼」或「文字」，因此依來源欄位長度保存實際值，不因代碼目前只有 1 碼就縮成 `varchar(1)`。顯示用的完整對照名稱不拼接寫入原始值欄位。
- 未回傳、來源空字串與明確的「無」分開處理，不將缺值自動改成 `0`、否或未婚。欄位超長時應回報介接資料異常，不以截斷方式入庫。

下列表格只列勾選的來源業務欄位；主鍵、查調批次關聯及建立時間沿用既有查調結果模型。欄位英文名稱為本平台命名，不代表戶政 JSON 的原始鍵名。

## 1. 戶政人員查調結果（單表）

資料表：`enquiry_household_member_result`。CQ03 與 CQ26 的資料合併保存在同一張表，同一查調批次、同一位人員保存一筆。

CQ03 勾選 10 項、CQ26 勾選 19 項；其中統號、姓名、出生日期、婚姻狀況及配偶姓名共 5 項重複，合併後共 24 個業務欄位。各欄說明保留來源表單及項目編號。

| 1 | 統號 | `national_id` | `varchar(10)` | CQ03 項目 01／CQ26 項目 06，皆為 `X10`。兩來源共用此欄，保存該位人員的統號原值，保留英文字母及數字，不轉數值型別。 |
| 2 | 姓名 | `name` | `varchar(200)` | CQ03 項目 02，`C6/C50;C200`；CQ26 項目 07，`C20/C50;C200`。兩來源共用此欄，中文姓名最多 50 字，原住民族文字姓名最多 200 字。 |

### 資料合併方式

- 以同一查調批次及人員統號對應兩來源資料，不以姓名合併；不同批次保留各次結果。
- CQ03 的地址、遷入日期、特殊記事及原住民身分，只寫入實際查到的該位人員，不套用給其他同戶成員；未查得的欄位保留 NULL。
- CQ26 每個人員的戶長統號，依其所屬的全戶資料組取得；不能將所有人都套用第一組戶長。
- 合併時未回傳的欄位不清空既有回傳值；共用欄位若兩來源不一致，記錄差異並依既有原始回應確認，不以最後寫入者直接覆蓋。

### 個人記事的多筆處理

`personal_notes` 使用 PostgreSQL 陣列型別，元素型別為 `varchar(1000)`；`[]` 不限制回傳筆數。PostgreSQL 支援以元素型別後綴 `[]` 宣告陣列，參閱 [PostgreSQL 陣列型別](https://www.postgresql.org/docs/current/arrays.html)。

來源明確回傳無記事時保存空陣列 `{}`；未取得記事欄位時保存 `NULL`。不將多筆記事以分隔符號拼接成一個 `varchar(1000)`，也不建立「記事一、記事二」等固定數量欄位。

## 來源對照確認事項

1. 代碼彙整提供婚姻、特殊記事、原住民身分、養父母註記及個人註記的對照值；正式介接時仍須確認各來源 JSON 欄位實際回傳的是代碼或文字。遇到未列代碼時保留原值並標記待確認，不當成無資料。
2. 稱謂、雙親註記及個人記事全文的完整取值不在本次代碼彙整內；以正式介接欄位說明及回傳樣本確認，不杜撰代碼。
3. CQ26 的原住民身分、遷入日期、戶籍地址等項目未標示「■」；合併表中的這些欄位僅由 CQ03 已勾選項目提供，不視為 CQ26 有回傳。
4. 索引條件的「A1 多筆統號」及資料規格的 UTF-8 JSON 為查詢／傳輸設定，不另設為人員資料欄位。
