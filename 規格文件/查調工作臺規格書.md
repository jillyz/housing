供授權承辦人查詢案件、核對成員、檢視跨機關查調結果與資格初判，並查閱歷次查調、閱覽紀錄及匯出 Excel。資格初判供審查參考，不等同最終核定。

| 項目 | 對應內容 |
|---|---|
| 案件列表 | [查調工作臺](../backend/enquiry-hub.html) |
| 案件明細 | [查調案件詳細資料](../backend/enquiry-detail.html) |
| 查調請求與介接 | [跨機關查調機制](跨機關查調機制.md) |
| 戶政欄位及代碼 | [戶政查調資料表設計](戶政查調資料表設計.md)、[戶政資料代碼彙整](戶政資料代碼彙整.md) |

本文件以現行畫面及已確認需求為主。頁面目前為互動原型，使用固定資料，尚未串接正式查調、權限及稽核服務；原型與正式介接的差異列於第九節。

## 二、查調流程與狀態

### 2.1 兩階段處理

1. **確認案件成員**：先取得申請人戶政資料與全戶名單，核對案件是否少列或多列成員；有偶時核對申請人配偶，必要時取得配偶戶籍。
2. **完整資料查調**：必要成員確認後，依受查範圍與個人授權查調社福資格、所得、不動產及動產，再計算資格初判。

戶籍名單不直接等於財稅受查名單或家庭計算人口。寄居者不因同戶而自動納入；兄弟姊妹亦不得僅因同父母就視為直系親屬。關係不明時保留人工核對。

### 2.2 頁面狀態

| 狀態 | 意義 | 列表資格初判 | 明細與操作 |
|---|---|---|---|
| 成員未完備 | 案件成員有少列、多列或其他待確認事項 | 六格淡黃底、留白，不放等待圖示 | 可開明細核對案件及已回傳戶政資料；列出待補齊／待排除成員，尚未查調項目不初判 |
| 查調中 | 完整查調正在執行 | 六格灰底、留白，不放轉圈圖示 | 操作欄留白；直接開明細網址亦不得顯示查調內容 |
| 查調完成 | 已完成本次必要查調與判斷 | 顯示各項結果 | 可檢視完整資料、歷次查調及檢視紀錄 |

三種查調狀態與申請案件的受理、入住、退租狀態分開管理。成員齊全不代表未授權、來源失敗或資料不足的項目已完成；相關項目須保留原因，不將來源失敗寫成「查無資料」或零值。

### 2.3 配偶核對與查調範圍

- 申請人婚姻狀況為「有偶」時，取得配偶姓名，再以姓名比對案件成員。
- 未比對到配偶時，依本案流程標記「配偶分戶」，提示配偶未填列；已列配偶仍須核對是否與申請人同戶。
- 配偶已填列且同戶、已填列但分戶，均保留相應戶籍分組。同一人跨戶或跨來源只計一次。
- 姓名比對用於核對及找出配偶需求；正式介接須以來源身分證字號確認同一人。姓名重複或無法取得配偶身分時，保留待確認，不猜測身分。
- 僅延伸申請人的配偶，不因其他家庭成員有偶就繼續追查其分戶配偶。
- 正式查調依 `query.scope` 決定僅案件成員、全戶含寄居或全戶但寄居互斥；依 `query.skipSpouseInquiry` 決定是否不查調配偶，詳細規則沿用介接文件。現行畫面尚無此註記控制項。

### 2.4 授權與計算人數

- 案件成員逐人顯示「是否同意授權查調」。正式執行須逐人逐項檢核；未同意不執行其需授權項目，亦不將資料缺漏當成 0。
- 家庭總人數**一定包含胎兒**。正式查調由需求方自行計算，於請求傳入 `familyTotalMemberCount`；平台直接採用，不以成員筆數、戶籍人數或已授權人數重算，也不再加一次胎兒。
- `familyTotalMemberCount` 必須為正整數；缺漏或不合法時拒絕請求，不自行補值。不查調配偶亦不自動增減此分母。

## 三、案件列表

### 3.1 查詢與分頁

| 功能 | 規則 |
|---|---|
| 關鍵字 | 查詢統一案件編號、申請人姓名；原型另支援情境名稱與描述。去除前後空白，不分英文大小寫，以包含文字比對 |
| 權責機關 | 可選全部或指定機關 |
| 查調狀態 | 全部、成員未完備、查調中、查調完成 |
| 查詢／重設 | 條件間取交集；按「查詢」才套用，重設清除條件，兩者均回第一頁 |
| 排序 | 原型先列配偶未填列案件，同組維持既定順序；不另設案件情境欄 |
| 每頁筆數 | 預設 20 筆，可切換 10、20、50、100 筆 |
| 分頁操作 | 第一頁、上一頁、頁碼、下一頁、最後一頁及指定頁碼；不可跳到範圍外或非整數頁碼 |
| 筆數切換 | 保留原第一筆所在的新頁面；翻頁不套用尚未送出的查詢條件 |
| 查無資料 | 顯示提示，匯出按鈕停用 |

列表顯示筆數範圍、總筆數及目前頁次。首頁、末頁及只有一頁時，對應的不可用操作停用。

### 3.2 欄位與結果

欄位依序為：**統一案件編號、申請人、申請社宅、權責機關、查調狀態、資格初判六項、操作**。

| 資格初判欄位順序 | 顯示規則 |
|---|---|
| 總所得 | 實心勾號＝未超標；實心驚嘆號＝超標 |
| 每人每月平均所得 | 同上 |
| 無自有住宅 | 實心勾號＝無持有；實心驚嘆號＝有持有；必要資料不足顯示待確認 |
| 不動產價值 | 實心勾號＝未超標；實心驚嘆號＝超標 |
| 動產價值 | 同上 |
| 租金級距 | 只顯示「第 X 級」；超出級距或尚未判定時留白，不放圖示 |

- 案件情境以編號旁的 **[?]** 提示呈現，不占獨立欄位；金額結果可透過提示查看數值與是否超標。
- 查調中不提供操作按鈕；其餘案件提供「查看詳細」。
- 統一案件編號完整顯示，格式為機關代碼 2 碼＋民國年度 3 碼＋縣市代碼 1 碼＋流水號 8 碼，共 14 字元，保留前導零。
- 桌機欄位標題不換行，寬表可橫向捲動；小螢幕改為逐案顯示欄名與內容。

## 四、案件明細

### 4.1 頁面結構

頂端保留案件查調狀態、檢視次數與返回列表。其下顯示目前查調批次、是否目前採用、送查調時間、完成時間、保存期限及「歷次查調紀錄」。

內容依序為：**兩階段進度與成員提示 → 案件資料 → 查調結果 → 家庭成員／共居者 → 社福資格 → 所得 → 不動產 → 動產**。

各資料區可展開／收合。成員未完備時保留案件資料、戶政核對與未查調提示；完整查調完成後，結果區另提供五類資料的頁內跳轉入口。

### 4.2 案件資料

桌機兩排四欄；較窄畫面兩欄，手機一欄。

| 排列 | 第 1 欄 | 第 2 欄 | 第 3 欄 | 第 4 欄 |
|---|---|---|---|---|
| 上排 | 統一案件編號 | 申請人 | 申請時間 | 查調基準日 |
| 下排 | 申請社宅 | 申請房型 | 社宅所在縣市行政區 | 權責機關 |

此區不重複列查調狀態。基本資料取自案件資料；正式串接時依查調批次快照呈現，不以最新主檔覆蓋歷史內容。

下方「案件成員」包含：

- 總人數：顯示「總人數：N 人（含胎兒）」，不再拆寫成員數加胎兒數。
- 成員表格：**姓名｜與申請人關係｜身分證字號｜是否同意授權查調**。
- 有胎兒的成員，於姓名下顯示胎兒數；申請人關係使用「本人」。

### 4.3 家庭成員／共居者（戶政司）

上方顯示申請人婚姻狀況；有偶時另顯示配偶姓名、同戶／分戶及是否已填列。

戶籍名單分為「申請人戶籍」與必要的「配偶戶籍（分戶）」。案件內已列、但不在這兩戶的人，另列「非申請人戶、非配偶戶」，於每位成員的「與申請人關係」右側獨立「提醒」欄顯示「案件多列成員，須排除」，標籤樣式與「未填列」相同；不與關係文字放在同一格，也不放在標題旁或個人註記欄。

「非申請人戶、非配偶戶」本區依序列**姓名、與申請人關係、提醒**，前兩欄寬度與其他戶籍表一致。以案件既有資料供核對與補正，不顯示身分證字號、生日、戶長稱謂、父母／養父母及個人記事。依本案排除規則，不再額外對多列者執行個人戶政、社福、所得及財產查調；整案維持成員未完備，待名單補正後再查調。

| 欄位 | 顯示規則 |
|---|---|
| 姓名 | 戶政回傳姓名 |
| 與申請人關係 | 取案件填列關係；非案件成員顯示醒目的「未填列」 |
| 身分證字號、生日 | 已填列案件成員顯示；未填列者留白 |
| （稱謂）與戶長關係 | 顯示戶籍稱謂；表頭「（稱謂）」與「與戶長關係」分兩行，不等同與申請人關係 |
| 父／養父、母／養母 | 顯示有資料的父母及養父母；只有養父而無父親資料時，不另列「父：無」 |
| 註記 | 顯示有養父母、輔助宣告及可展開的多筆個人記事；記事顯示類型與內容，不顯示代碼 |

樣式規則：

- 已填列成員使用白底；**未填列者使用淡黃底，僅顯示姓名、戶籍稱謂及「未填列」標記**，其他個資與註記留白。
- 其他案件成員只標示該成員列的淡橘底，不將整個區塊上色；有此類多列成員時判為「成員未完備」，頂端另列待排除姓名，暫不提供完整查調及「模擬補齊」操作；剔除後仍須依確認後名單重新查調。
- 「有養父母：否」「無個人記事」不顯示；不再加「未列入案件」等重複文字。
- 無符合、無資料、未登載等次要內容使用淡色，不能因此推定資料已完成或資格符合。

個人記事的代碼及記事例內容參閱 [戶政查調資料表設計](戶政查調資料表設計.md) 所附來源。

### 4.4 五類查調資料

| 區塊 | 欄位與摘要 |
|---|---|
| 個人資料 | 併於「家庭成員／共居者（戶政司）」呈現，不另重複一份名單 |
| 社福資格（衛福部、戶政司） | 姓名、社福資格、查調結果；同一人可有多項資格，育有未成年子女時逐一列名 |
| 所得（財政部） | 所得年度、總人數及所得查調年度規則；表格為姓名、所得年度、年所得合計；下方列全案年所得及每人每月平均所得 |
| 不動產（地政司） | 先顯示無自有住宅總結果及五項條件，再列九欄財產明細與納入計算總額 |
| 動產（財政部） | 利率、動產限額；表格為姓名、利息（存款本金）、中獎所得、其他所得、小計；下方列全案動產總額與算法 |

不動產九欄依序為：**持有者｜類別｜地段地號建號／座落｜戶籍地｜持分比｜房地面積｜房地現值金額｜公同共有｜原住民保留地、道路用地**。

布林欄位可用圖示表示是／否，並提供文字提示。桌機明細欄位不強制換行，超寬時在表格內捲動。不另加「不動產明細」標題。

所得區塊表格上方說明文字：「所得查調年度依查調基準日判定：4 月 28 日前採前二年度所得；4 月 28 日起（含當日）採前一年度所得。」年度均以查調基準日所屬年度往前推算。

## 五、資格初判與計算

### 5.1 所得與財產

結果區以「本案、標準值、資格初判」三列對照，欄位依序為：**總所得、每人每月平均所得、無自有住宅、不動產價值、動產價值、租金級距**，與列表順序一致。

「無自有住宅」本案列顯示有持有／無持有，標準值為無持有自有住宅，初判以實心勾號／驚嘆號及符合／不符合呈現，與下方五項住宅條件使用同一判斷結果。未查調顯示等待提示，必要資料不足顯示待確認，不預設為符合。

| 項目 | 計算或判斷 | 原型參考設定 |
|---|---|---|
| 總所得 | 納入計算之家庭成員年所得加總 | < 1,450,000 元 |
| 每人每月平均所得 | 年所得合計 ÷ 12 個月 ÷ 總人數（含胎兒） | ≤ 62,125 元 |
| 不動產價值 | 納入計算之房地現值加總，排除原住民保留地及道路用地 | < 7,080,000 元 |
| 動產價值 | 各人換算存款本金＋中獎所得＋其他一次性給予所得，再加總 | < 4,710,000 元；利率 1.67% |

上述金額為目前原型參考值；正式標準取該批次保存的參數，不將範例固定為通用審查標準。嚴格小於的項目，金額等於限額即不符合。

動產計算：

```text
個人存款本金＝利息 ÷（interestRate ÷ 100）
個人動產價值＝存款本金＋中獎所得＋其他一次性給予所得
全案動產價值＝納入計算成員的個人動產價值加總
```

- 利率參數 `1.67` 表示 **1.67%**，計算時才轉為 `0.0167`；不可直接以 `1.67` 當除數。
- 畫面加註「動產價值 = (利息 ÷ 1.67%) + 中獎所得 + 其他所得」；百分比隨實際採用利率顯示，不另寫參數設定說明。
- 動產表格的利息欄只顯示利息金額，**不顯示換算後的存款本金值**；有價證券不顯示，也不納入本工作臺動產計算。
- 原住民保留地、道路用地保留原始明細與金額，標註「不納入計算」，同時排除不動產總額與自有住宅判斷。
- 原型平均所得與逐人換算存款本金均四捨五入至元；正式計算精度及比較時點須與介接規則一致。

### 5.2 無持有自有住宅

總結果「**無持有自有住宅：**」優先顯示，實心勾號或實心驚嘆號緊接文字，避免與其他結果混淆。下方保留五塊條件，各顯示是／否；為「是」時標紅，資料不足時顯示「待確認」。

以下均以公告範圍縣市內、未屬排除用地的住宅為判斷對象；一般土地及非住宅財產不直接視為住宅。

| 序號 | 條件名稱 | 判斷重點 |
|---|---|---|
| 1 | 於公告範圍縣市有自有住宅 | 任一受查家庭成員持有範圍內住宅即為是；**此項本身即足以判定有持有自有住宅** |
| 2 | 完全持有住宅(持分為1) | 個人持分分子等於分母 |
| 3 | 個別持有共有住宅面積>40㎡ | 房屋面積 × 個人持分 > 40㎡；恰為 40㎡不成立此項 |
| 4 | 戶籍設於持有住宅地址 | 持有人的戶籍設於所持住宅地址，即成立此項 |
| 5 | 多名家庭成員持有同一共有住宅:持分合計為1(完全持有)或換算面積≥40㎡ | 至少兩名成員持有同一住宅；持分合計為 1，或換算面積合計 ≥ 40㎡ |

- **任一項為是**：判定有持有自有住宅，總結果顯示紅色實心驚嘆號。
- **五項皆否且必要資料完整**：判定無持有自有住宅，總結果顯示綠色實心勾號。
- 已知條件為是時可確定有持有；尚無確定命中且資料不足時保留待確認，不顯示勾號。
- 公告縣市不直接羅列於卡片；以第一項旁 **[?]** 展開查看具體縣市。範圍取參數，不以申請人戶籍縣市代替。
- 同一住宅依來源識別資料歸組，同一人同一住宅先去重；不跨不同住宅合計面積或持分，不以畫面四捨五入後的比例計算。
- 無自有住宅與不動產價值為兩項獨立初判，不得以房地總額未超標推定無自有住宅。

正式 API 判定碼沿用 `selfOwnedHousing`：`1`＝有、`2`＝無、`NULL`＝未判定。第 1 項的現行判法與舊介接文件差異見第九節。

### 5.3 租金級距

原型先判斷每人每月平均所得是否超過 62,125 元；超過即留白，其餘依序套用：

| 級距 | 原型條件 |
|---|---|
| 第 1 級 | 家庭成員有低收入戶或中低收入戶資格 |
| 第 2 級 | 不符第 1 級，平均所得 ≤ 26,624 元 |
| 第 3 級 | 不符前兩級，平均所得 ≤ 62,125 元 |

明細可展開查看級距。正式介接改依該批次傳入的級距順序、弱勢類別、所得區間及 AND／OR 條件判定，不以原型三個級距取代正式設定；無法判定時保留原因。

## 六、歷次查調與檢視紀錄

### 6.1 查調批次

- 一次查調對應一個「查調批次」；「目前採用版本／歷史版本」用於說明目前檢視內容，不另混用批次與版次編號。
- 歷次查調以新至舊排列，欄位為：**批次｜送查調時間｜查調狀態｜保存期限｜操作**；標示目前採用批次。
- 點選「檢視」切換整頁至該批次，保留返回目前採用版本的入口；檢視不會將歷史批次改為目前採用。
- 正式批次須保存當時案件資料、成員與授權、總人數、基準日、查調範圍與註記、標準參數、來源結果及初判；日後主檔或參數變動不得回寫歷史內容。
- 原型以送查調時間加六個月為保存期限，月份無相同日期時取月底；到期或批次不存在時不顯示內容，提供返回入口。正式起算點與刪除範圍依介接文件另行確認。

### 6.2 檢視次數

- 成功開啟一個可檢視批次即累計一次；重新開頁或切換歷史批次亦計次。只開啟紀錄視窗不另計次。
- 次數以案件累計；點選「檢視次數」開啟紀錄，欄位為：**檢視時間｜檢視人員｜所屬機關｜查閱批次**，新紀錄在前。
- 查無案件、查調中及無效／到期批次不累計檢視。
- 原型以瀏覽器本機儲存累加，顯示最近 100 筆；儲存不可用時仍可檢視。正式紀錄須由後端記錄實際登入人員，不以本機數值作稽核依據；閱覽軌跡保存期限與查調內容分開管理。

## 七、Excel 匯出

### 7.1 匯出範圍與格式

- 從列表匯出**目前已套用篩選條件的全部案件**，包含其他頁，順序與查詢結果一致；尚未按查詢的條件不影響匯出。
- 檔名為 `查調案件_YYYYMMDDHHmmss.xlsx`，時間採臺北時區；工作表名稱「查調案件」。
- 固定 16 欄，首列為欄名，凍結首列、啟用篩選；多位姓名在同一格內斷行，未成年子女人數使用數值。
- 判斷符號存為文字 `V`、`!`，不是圖片或 Excel 圖示；各欄的成立條件見下表，不將所有驚嘆號解讀為資格不符。
- 未取得或無法判斷的值留白。查調中只匯出前三項基本欄位；成員未完備可匯出已知資料，但原住民及財務初判等尚未查調資料留白，不輸出未填列者的隱藏個資。
- 匯出中停用按鈕，避免重複送出；成功提示筆數，失敗提示原因並允許重試。無符合案件時停用匯出。

### 7.2 欄位定義

年齡及連續設籍期間均以**申請日**判斷。年齡、未成年子女、原住民及養父母欄位以已填列案件成員為範圍，不包含胎兒及未填列者；設籍兩欄、婚姻及配偶判斷以申請人為主。

| 序號 | 欄位 | 內容與判斷 |
|---|---|---|
| 1 | 統一案件編號 | 完整字串，保留前導零 |
| 2 | 申請社宅 | 社宅名稱 |
| 3 | 申請人 | 申請人姓名 |
| 4 | 年齡(成年) | 全員滿 18 歲為 V；有未滿 18 歲者為 !，下方逐行列未成年者姓名 |
| 5 | 年齡(65歲) | 有滿 65 歲者為 V，並逐行列姓名；皆未滿為 ! |
| 6 | 設籍地 | 申請人戶籍縣市＝社宅所在縣市為 V，否則 ! |
| 7 | 連續設籍滿1年 | 申請人設籍於社宅所在縣市及行政區，且申請日已達遷入一週年為 V，否則 !；閏日遷入於次年二月底滿一年 |
| 8 | 有無配偶 | 申請人婚姻狀況有偶為 V，無偶為 ! |
| 9 | 配偶分戶 | 依配偶核對結果，分戶為 V，同戶或無配偶為 !；有偶但未取得配偶姓名時留白 |
| 10 | 未成年子女 | 比對父／母／養父／養母姓名是否為申請人，且未滿 18 歲的已列成員人數；不以稱謂或胎兒數代替 |
| 11 | 原住民 | 每人一行「姓名：V／!」，表示該人是否具原住民身分 |
| 12 | 有無養父母 | 每人一行「姓名：V／!」，有養父或養母即為 V |
| 13 | 總所得 | 未超標 V、超標 ! |
| 14 | 每人每月平均所得 | 未超標 V、超標 ! |
| 15 | 租金分級 | 顯示「第 X 級」；未取得級距留白 |
| 16 | 動產 | 未超標 V、超標 ! |

現行 Excel 不含不動產價值、無自有住宅、房型及查調狀態欄，亦沒有匯入功能。未來如提供匯入，須明訂 `V`、`!`、空白及姓名斷行格式的解析規則，不把空白視為否。

## 八、驗收重點

| 情境 | 應確認結果 |
|---|---|
| 漏列配偶（同戶／分戶） | 列表優先呈現未填配偶案件；明細顯示配偶姓名與填列狀態，未完備時不執行完整查調 |
| 漏列女兒、漏列長輩及配偶 | 未填列者淡黃底，只顯示姓名、稱謂及未填列標記 |
| 配偶分戶且兒子在配偶戶 | 正確分組，案件成員、所得及人口不重複計算 |
| 配偶已填列且有 1 名胎兒 | 五位成員加胎兒為 6 人；正式畫面與平均所得均採請求傳入的 6，不重加胎兒 |
| 養父及輔助宣告 | 張忠政顯示養父張大富及有養父母註記；張大富顯示輔助宣告，由張忠政擔任輔助人；不顯示記事代碼 |
| 長輩有分戶配偶 | 不延伸為申請人配偶查調需求 |
| 其他案件成員 | `CH115F00000011` 的張曉雯另區列示，只標色成員列並提示剔除；狀態為成員未完備、列表六格黃底留白，明細不顯示完整查調結果；不得直接改寫原案件 |
| 無財產／僅有排除用地 | 已確認無財產時合計為 0；排除用地保留明細但不計金額及住宅結果 |
| 住宅五項條件與邊界 | 第一項為是即總結果為驚嘆號；個人面積恰 40㎡不命中第三項，多人合計恰 40㎡命中第五項；各條件獨立呈現 |
| 超標案件 | 相應初判顯示驚嘆號，超出所得級距時租金級距留白 |
| 查調中 | 六格灰底且無操作按鈕；直接網址也不能檢視明細或增加檢視次數 |
| 歷史、失效批次與錯誤案件 | 切換後資料對應所選批次；無效或到期不顯示內容，提供返回入口 |
| 分頁與匯出 | 預設 20 筆；換頁不套用未送出條件；匯出包含所有已篩選頁面並保留斷行、V／! 及空白 |

三代範例以張大富、張忠政、劉欣慧、張曉雯、張曉晨為共同基底；陳 OO、廖 OO 為寄居者。張大富包含 65 歲以上、輕度身心障礙資格；張忠政包含中低收入戶、平地原住民及兩名未成年子女。

## 九、原型與正式串接差異

以下為實作銜接事項，不代表畫面已具備正式後端能力。

| 項目 | 現況與銜接要求 |
|---|---|
| 人數與授權 | 原型依固定名單加胎兒產生展示人數，授權也使用固定資料；正式版須直接採用批次的 `familyTotalMemberCount`，並落實逐人逐項授權，不能沿用展示判定 |
| 多列成員 | 原型已將多列成員納入未完備判斷，保留原填列名單及人數，暫停完整查調與財務初判；尚無正式剔除及重查流程。正式版須先完成人工確認與補正，再以確認後名單、新總人數及新批次更新結果，不直接自動刪除 |
| 住宅規則差異 | 現行畫面五項任一為是即判有住宅；既有介接文件 4.3.3 仍以公告範圍作篩選，再判其餘四項。兩者須同步，尤其不能將僅命中第一項的案件判成無住宅 |
| 標準與級距 | 原型使用固定門檻、三個級距及整元計算；正式版須採批次參數與計算精度，補上自訂級距的條件、AND／OR、子條件結果及缺漏原因 |
| 歷史與閱覽 | 原型歷史主要切換成員快照，其他資料仍共用固定來源，檢視次數僅存本機。正式版須保存完整批次快照及後端閱覽紀錄，並落實到期存取限制 |
| 啟動查調 | 正式查調由既有 API 接收；「模擬補齊成員並查調／還原」只是原型導覽，不是正式補正或重新查調功能。不在本文件新增 API 端點 |
